# 从"不敢喂"到"放心用"

> **From "Dare Not Feed" to "Use with Confidence"**
> AI 财务数据分析的脱敏闭环与工具化落地 —— 一套纯 HTML 制作的 10 分钟价值分享演示文稿

---

## 这是什么

一场面向财务团队的 AI 实践分享，讲了一个完整的故事：

**为什么不敢把财务数据喂给 AI → 如何用"脱敏闭环"做到放心喂 → 如何把一次对话沉淀成一套可复用的工具 → token 应该花在哪里 → 下一步让 AI 真正懂业务。**

整套演示不依赖任何框架，是**一个纯手写的单文件 HTML**。
